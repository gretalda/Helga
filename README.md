# АстроЛично — Хорар · версия 0.5.0

Открытая демонстрационная версия приложения с расчётом хорарной карты (Swiss Ephemeris / Moshier), системой домов Региомонтана и объяснением на русском языке.

Живой сайт: https://astrolichno-horary-demo.onrender.com

## Для пользователей

1. Напишите **один конкретный вопрос** своими словами, не выбирая заранее тему.
2. Укажите город и момент, когда возник/был понят вопрос.
3. Нажмите «Получить ответ и построить карту».
4. Если приложение не может корректно определить участника вопроса, уточните его в появившемся поле; есть пункт «Другое» и ручной выбор дома для специалистов.
5. Сначала вы увидите понятный ответ, ниже — карту и астрологические аргументы.

Программа различает вопросы **да/нет**, **когда**, **что происходит**, **к чему идёт ситуация**. Сроки, указанные числом и некоторыми словесными выражениями, могут извлекаться из вопроса; перед использованием проверяйте, что приложение поняло срок правильно.

## Что именно вычисляется

- 7 традиционных планет, 12 куспидов домов, управители домов, прямое/ретроградное движение.
- Основные аспекты, поиск ближайшей астрономической точной перфекции до смены планетами знаков.
- Ближайшие аспекты Луны до ингрессии.
- Полные рецепции обеих сторон по пяти достоинствам: обитель, экзальтация, триплицитет (дневная/ночная карта), птолемеевы термы и халдейские деканы; одностороннее и взаимное принятие, изгнание/падение, оценки эссенциальной силы.
- Кандидаты на дополнительные аспекты третьей планеты до предполагаемой перфекции, а также предварительные кандидаты на перевод/собирание света.
- Частично — производные дома для распознанных вопросов об отношениях бывшего партнёра с новой романтической партнёршей и некоторых вопросах про детей.

**Критично:** автоматический текст — *предварительная символическая трактовка*, не факт о людях и не гарантия результата. Астрономическое время до аспекта **не является** прогнозом даты события. Кандидаты на «запрет», перевод и собирание света — не завершённое хорарное суждение Лилли: нужны полноценные проверки принятия света, определения домов, стационарности и запретов. Рецепции по пяти достоинствам рассчитываются автоматически, но трактовка не заменяет эксперта. Не полагайтесь на ответы программы в финансовых, медицинских, юридических или иных важных решениях.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Windows: `.venv\\Scripts\\activate` вместо `source .venv/bin/activate`.
Откройте http://127.0.0.1:8000 в браузере.

## Тестирование

```bash
PYTHONPATH=. pytest -q
```

## Публикация

Исходники хранятся в https://github.com/gretalda/Helga, сервис Render использует ветку `main` и автоматически разворачивает изменения. **Обычным пользователям скачивать или вставлять исходники не требуется.**
