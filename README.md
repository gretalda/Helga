# АстроЛично — астрологическое веб-приложение (v1.1, тестовая версия)

Это открытый веб-кабинет, объединяющий ранее отдельный хорарный калькулятор с персональными астрологическими расчётами по образцу Telegram-бота AstroLichno. **Это самостоятельная реализация интерфейса и расчётных отчётов; она не является полным переносом всех авторских текстовых модулей и функций Telegram-бота.**

## Разделы

- Твой день: личные транзиты на выбранную дату.
- Прогноз на период: расчётные окна транзитов, до 94 дней включительно.
- Транзиты: мажорные связи с наталом на дату и календарные окна.
- Соляр: точный момент возвращения Солнца к натальной долготе, дома места встречи соляра и межкартные аспекты.
- Лунар: последний точный возврат Луны к натальной долготе на указанную местную дату, цикл до следующего возвращения.
- Натальная карта: планеты, Плацидус, аспекты, основные сферы жизни.
- Совместимость: синастрия двух карт (аспекты, подробные тематические фразы).
- Вторичные прогрессии (1 день = 1 год), символические дирекции (1° в год).
- «Мой знак»: символические темы и традиционный управитель знака.
- Хорар: доступен отдельно на `/horary`, весь прежний API `/api/horary` сохранён.

Для точной натальной Луны, Асцендента и домов необходимо проверенное время рождения. В режиме неизвестного времени Луна и дома исключаются из натальной карты, а в качестве технического полудня используются только остальные планеты. При ручном выборе места требуется широта, долгота и IANA часовой пояс; в соляре и лунаре дополнительно место фактического возвращения.

## Архитектура

- `main.py`: FastAPI с API и отдельным старым хораром.
- `astro_portal.py`: расчёты Swiss Ephemeris в режиме Moshier.
- `forecast_writer.py`: связная консультационная интерпретация соляра, лунара, транзитов, прогрессий, дирекций, дня и периода, использующая вычисленные аспекты и дома.
- `static/portal.html`: светлый адаптивный интерфейс, профили в локальном `localStorage`.
- `static/index.html`: исходное приложение хорара.
- `tests/test_portal.py`: новые проверочные сценарии.

Расчёты оформлены независимо от Telegram и его хранения профилей, очередей и Stars. В этой тестовой версии нет полноценной синхронизации с аккаунтом Telegram, магазина, оплаты, событийного слоя ИИ или универсального распознавания вопросов. Подробная авторская консультационная трактовка, подобная Telegram-боту, потребует дополнительного переноса редакционных правил, проверки по ZET, тестирования периодов и настройки ИИ для нестандартных вопросов. Нельзя гарантировать реальные события на основании символической карты.

## Локальный запуск

```bash
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000
```

Главная: `http://127.0.0.1:8000/`. Хорар: `/horary`.

## Тестирование

```bash
PYTHONPATH=. pytest -q
```

## Обновление 1.1: консультационный стиль

Прогноз начинается с жизненного фона, затем следует разбор потенциальных проявлений и отдельно отношения, работа, финансы и семейная сфера. Прогрессии и дирекции показывают медленные тенденции, на основании временного сравнения определяется усиление/ослабление тесных аспектов (без заявлений о точных датах событий). Соляр и лунар сопоставляют дома возврата, фактическое место, натальную карту и межкартные аспекты. Техническая карта в интерфейсе перенесена после текста в раскрывающийся блок.

Все тексты являются рассчитанными сценарными интерпретациями, а не свободной генерацией ИИ; в неподтверждённых темах честно указывается недостаток показателей. **Это ещё не профессиональное прогнозирование с полной валидацией ZET и не перенос всех редакционных материалов бота.**

## Версия 1.2: Комплексный персональный прогноз

На главной странице выберите **Комплексный прогноз**, задайте начальную и конечную даты (до 94 дней), уточните город, где встречен соляр, и нажмите «Получить личный разбор». Требуется точное время рождения для домов.

Методы считаются отдельно и затем сопоставляются по жизненным темам:

- **Соляр** — текущий солнечный возврат и основной дом года. Если дата прогноза ещё до дня рождения, используется предыдущий действующий соляр.
- **Прогрессии** — метод день за год, орбис 0,8°; для прогрессивной Луны требуется известное время.
- **Символические дирекции** — 1° за тропический год, орбис 0,8° (не солнечная дуга по ZET по умолчанию, если её формула отличается).
- **Транзиты** — дневные замеры в 12:00, расчётное окно на выбранные даты. Сроки — окна аспектов, а не назначенные даты событий.
- **Лунар** — дополнительный месячный слой; он не увеличивает количество независимых долгих методов.

Синтез показывает обоснования каждого метода, количество поддерживающих методов и конкретные бытовые сценарии по отдельным сферам. Никаких процентных вероятностей не заявляется. Пустые аспекты не подменяются вымышленными событиями.

### Историческая валидация

В разделе по желанию можно вписать до 8 известных прошедших событий и до 8 контрольных дат. Формат строки: `ГГГГ-ММ-ДД | работа | краткое описание`. Поддерживаются темы: отношения, работа, деньги, дом, общение, самочувствие, планы, личное. Контроль: `ГГГГ-ММ-ДД | работа`.

К каждой дате выполняется отдельный расчёт **тех же** критериев; приводятся совпадения, расхождения и возможные ложные совпадения на контроле. Близость астрологических аспектов к биографии **не доказывает прогнозную точность**. Без контрольных дат нельзя оценить специфичность. Историческая проверка не заменяет независимого теста на невидимых алгоритму данных.

### Сверка с ZET

Открыть «Данные для сверки с ZET» в отчёте, выгрузить JSON и сравнить долготы натальных планет, прогрессий и дирекций. Для содержательного сравнения обязательны: одинаковые дата/место/исторический часовой пояс, тропический зодиак, Плацидус, Moshier/эфемериды, и совпадающая методика дирекций/прогрессий. **Автоматической интеграции с ZET и подтверждённых совпадений пока нет.**

Данные рождения и проверки передаются серверу только в рамках расчётного запроса; в приложении нет учетной записи и базы сохранения этих отчётов.
