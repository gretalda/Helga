# АстроЛично · Хорар 0.3.0

**Рабочий веб-прототип приложения (клиент + API + вычислительное ядро)**. Важно: PNG-файл с изображением интерфейса не является приложением. Для нажатия кнопок и расчёта карт необходимо **запустить веб-сервер** и открыть его адрес в браузере. На Android приложение работает по ссылке после развёртывания на хостинге; ZIP сам по себе не является APK.

## Что работает в версии 0.3

- Форма вопроса: семь тематических кнопок, ввод текста, обязательная дата и локальное время, город, время перехода часов, срок вопроса (если нужен).
- 19 городов с часовыми поясами, а также произвольный город по координатам и IANA-часовому поясу.
- Ручной выбор одного из домов II–XII для предмета вопроса. Это необходимо для вопросов, где дом не совпадает с темой.
- Система домов Региомонтана, ASC, MC, точные положения 7 традиционных планет Swiss Ephemeris с расчётным методом Мошье.
- Положения по домам, ретроградность, аспекты, орбисы, предварительный показатель сходящегося/расходящегося аспектного расстояния.
- Поиск точного будущего мажорного аспекта между управителями до выхода любой планеты из текущего знака; отдельный поиск аспектов Луны и предварительная пометка о Луне без курса.
- Эссенциальные достоинства по обители/экзальтации/изгнанию/падению, взаимная рецепция по обители.
- Предварительная интерпретация с подтверждающими показателями и предупреждениями; учёт явно введённого срока вопроса.
- Интерактивный расчёт через API, SVG-круг, список планет, таблица аспектов, копирование разбора, скачивание SVG и JSON, печать, история 5 последних карт в localStorage.
- PWA-манифест и доступность установки ярлыка на главный экран по HTTPS (для расчётов нужен сервер).
- Проверка доступности расчётного сервера прямо в интерфейсе.

## Быстрый запуск на компьютере

Требуется Python 3.11+.

Windows: запустите `start_windows.bat` либо вручную:
```
py -m pip install -r requirements.txt
py -m uvicorn main:app --host 127.0.0.1 --port 8000
```

macOS/Linux:
```
python3 -m pip install -r requirements.txt
python3 -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Откройте в браузере **http://127.0.0.1:8000/**. На Windows `localhost:8000` — адрес только на этом компьютере; телефон его не увидит до развёртывания на хостинге.

## Render: публикация отдельным сервисом

- Разместите исходники в отдельном репозитории GitHub. **Не заменяйте существующий Telegram-бот**.
- Убедитесь, что выбрана стратегия лицензирования (см. ниже); публичная публикация под AGPL требует доступности полного соответствующего исходного кода пользователям сетевого сервиса.
- Web service на Render, runtime Python, `buildCommand: pip install -r requirements.txt`, `startCommand: uvicorn main:app --host 0.0.0.0 --port $PORT`, health `/api/health`.
- Либо используйте `render.yaml` (Blueprint). Проверьте реальные запросы из браузера и с телефона после выхода деплоя в `live`.

## Тесты

```
python -m pip install pytest httpx
python -m pytest -q
```

12 автоматических тестов проверяют ядро и HTTP API. На этом запуске 12/12 прошли. Также JS проверен командой `node --check` (синтаксические ошибки отсутствуют). **Полное E2E-тестирование кнопок в реальном браузере в текущем окружении недоступно из-за системной блокировки переходов Playwright/Chromium.** Поэтому после публичного деплоя необходимо дополнительно пройти проверки вручную на Android и desktop. Скриншот — только иллюстрация, не подтверждение интерактивности.

## Ограничения, важные до реальной продажи

- Это **не законченный профессиональный астрологический эксперт**: не реализованы запрет/воспрепятствование аспектам, полное собирание/перевод света, подробные рецепции, все достоинства (термы/фасы), традиционные методы проверки радикальности, интерпретация планет по контексту и автоматические повернутые дома.
- Близкий аспект и будущая перфекция различаются, но трактовка возможных событий не является достоверным прогнозом; астрологические методы не имеют научного подтверждения в предсказании событий.
- Результат — символическое предварительное суждение, а не психологическая диагностика и не доказательство чувств третьих лиц.
- Отсутствуют аккаунты, платёжная система, база данных и управление доступом. Никаких функций продажи пока нет.
- Перед массовым запуском: сверить 30–50 карт с ZET/другим независимым расчётом (даты, часы DST, координаты, дома и долготы), провести живое E2E-тестирование мобильного браузера, настроить лимитирование запросов, безопасное хранение и удаление пользовательской истории, HTTPS, юридические документы, платежи.

## Новое в 0.3.0 — удобный ответ без астрологических терминов

- Светлый бело-кремовый интерфейс с контрастным текстом и светлой хорарной картой.
- Вверху результата отображаются короткий ответ, объяснение и 2 конкретные причины; карта идёт следом.
- Подробный астрологический разбор и таблица аспектов скрыты в раскрывающемся разделе, но доступны по нажатию.
- Для вопросов с ответом «да/нет» простой вывод принимает одно из четырёх состояний: «Скорее да», «Скорее нет в указанный срок», «Возможно, но с трудностями», «Пока нет ясного “да”».
- Для открытых вопросов («Когда...», «Как...», «С кем...») система не выдумывает бинарный ответ: помечает необходимость уточнения, поскольку автоматический эксперт по срокам и сложным сюжетам ещё не реализован.
- Простая трактовка наследует ограничения исходного астрологического алгоритма: она не удостоверяет будущие события, не определяет чувства и мотивы третьих лиц и требует профессиональной валидации.
