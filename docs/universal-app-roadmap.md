# АстроЛично — универсальная версия: PWA → Android → iOS

## Фактическая архитектура
- Backend: FastAPI + Swiss Ephemeris / Moshier, вычисления остаются серверными.
- Frontend: существующий light UI в `static/index.html`, `/api/interpret`, `/api/horary`.
- PWA: `static/manifest.json`, service worker, PNG-иконки.
- Android: следующий этап — сборка через Trusted Web Activity / Bubblewrap после верификации PWA, владения HTTPS-доменом и Digital Asset Links; APK для тестов, AAB для Play.
- iOS: отдельная сборка с Capacitor и локально упакованным frontend (без голой WebView-обёртки); серверные расчёты остаются по HTTPS.

## Уже начатая адаптация
- Service worker кэширует только статические файлы и офлайн-экран.
- GET/POST API, пользовательские тексты вопросов и страницы с ответами не кэшируются service worker.
- Нет попыток рассчитать карту офлайн; офлайн-экран это явно объясняет.
- Не изменена астрологическая логика или интерпретационные правила.

## Обязательные проверки перед публикацией
1. В Android Chrome открыть HTTPS-сайт: manifest, 192/512 иконки, установка, запуск без адресной строки.
2. Отключить сеть и перезапустить приложение: офлайн-экран; восстановить сеть: успешный запрос `/api/health` и хорар.
3. Проверить, что после расчёта вопрос не остаётся в Cache Storage; отдельно оценить уже существующий localStorage с историей 5 вопросов.
4. Проверить DST, координаты, язык, случаи двух/трёх участников, производные дома, рецепции, явный ввод вручную, ошибку 422.
5. Проверить размер экранов, клавиатуру телефона, контраст, доступность формы, работу установки на Android и iOS.
6. Проверить cookie/политику данных/удаление истории, лимиты запросов, антиспам, лицензии и опубликованные условия.
7. Отдельно прогнать тесты вычислительного ядра и реальные хорарные кейсы. Предварительную трактовку нельзя рекламировать как гарантированный прогноз.
